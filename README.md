# Job Application Tracking System (Salesforce)

## Overview
This project is a Salesforce-based system to track job applications and automatically evaluate candidates based on experience.

## Features
- Custom Object: Job Application
- Fields: Candidate Name, Experience, Status
- Automated decision using Apex Trigger
- Validation Rule to prevent invalid data

## Logic
- Experience >= 3 → Shortlisted
- Experience < 3 → Rejected

## Tech Stack
- Salesforce
- Apex
- Triggers
